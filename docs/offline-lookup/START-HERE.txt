METRO RENT BURDEN — OFFLINE LOOKUP COMPANION
Ahmadreza Samadi | https://a-samadi.com/about.html

Use this small companion to find rows in the fixed ACS 2024 rent-burden dataset. It includes the same 386 whole-metro rows, 35 stored fields, custom dictionary and source metadata. No new observations, percentages or geographic matches are created.

START
Unzip the complete archive, preserving its raw/ subfolder. Use Python 3.12 or newer. No packages need installing. Run the commands from the unpacked folder; if your Python command is named python rather than python3, substitute that executable and keep the arguments.

1. Read one metro as text:
   python3 -B lookup_metro.py --code 38060 --format text

2. Search names and retain every original field in JSON:
   python3 -B lookup_metro.py --search "Phoenix"

3. Verify the stored CSV, dictionary and source metadata:
   python3 -B verify_dictionary.py

The supplied commands read local files and print to the terminal; they make no network requests and require no account or API key. They do not submit records or rewrite the CSV. The -B option avoids Python bytecode-cache files.

READ THE NUMBERS
The source universe is renter-occupied housing units. The 30%-plus and 50%-plus shares use units with a computable gross-rent-to-income ratio; units with no computed ratio are reported separately. The 50%-plus group is inside the 30%-plus group: do not add their shares. The not-computed percentage uses ALL renter-occupied units.

The text view summarizes stored values. Default JSON preserves all 35 columns and all 11 source estimate/MOE pairs. Derived percentage MOEs and statistical significance are not calculated. No search match is not zero burden; an absent explicit code is an input error. Read READING-GUIDE.txt and DATA-DICTIONARY.txt for interpretation.

This is a fixed 2024 statistical snapshot, not current asking rents, a property-level assessment or an investment ranking.
